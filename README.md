# ماه طلا

سایتی که کاربر عکس دستش را می‌دهد و انگشتر را روی انگشت خودش می‌بیند.

**وضعیت:** نسخه‌ی اول ساخته شده (یک انگشتر). با یک سرور ساده باز می‌شود: `python3 -m http.server` و بعد `http://localhost:8000`.

- موکاپ دو صفحه‌ی اصلی (شروع و امتحان): `docs/mockup.html` (در مرورگر باز کنید)
- تصمیم‌ها و برنامه: `CLAUDE.md`
