# ابزارهای ساخت انگشتر (آپلود نشود)

این پوشه جزو سایت نیست و روی هاست آپلود نمی‌شود. برای ساختن عکس آماده‌ی یک انگشتر تازه از عکس محصول است.
(پایتون + `opencv-python-headless` + `numpy` لازم است.)

سایت انگشتر را «دوباره نورپردازی» می‌کند، پس فایل انگشتر باید **نورِ استودیو را نداشته باشد** (آلبدو) و
یک فایل دوم برای ردپای زیرِ انگشتر (`-fill.png`) داشته باشد. دو مسیر:

**انگشتر مشبک یا با سوراخ (مثل «مشبک»):** عکس روبه‌رو با پس‌زمینه‌ی تقریباً سفید.
1. `ring-asset/build-face-open.py عکس.png پوشه‌ی‌خروجی ring-NN [پوشه‌ی‌دیباگ]`
   ← سوراخ‌ها را شفاف می‌کند، پشتِ حلقه را حذف می‌کند، لبه‌ی خمیده را صاف می‌کند، نورِ استودیو را برمی‌دارد.
   اگر پشت‌حلقه (مهر و عیار) بالای رویه می‌ماند، دیباگ را ببینید (`_masks.png`: سبز = دهانه‌ی حلقه).
2. `ring-asset/thumb-colored-bg.py عکس-سه‌چهارم.png assets/rings/ring-NN-thumb.png` ← عکس کوچک انتخاب.

**انگشتر توپر (مثل «سه‌رنگ»):**
1. `ring-asset/1-cutout.py عکس.png بریده.png پیش‌نمایش.png`
2. `ring-asset/2-straighten.py بریده.png رویه.png پیش‌نمایش.png`
3. `ring-asset/delight-solid.py رویه.png assets/rings/ring-NN.png assets/rings/ring-NN-fill.png`
4. `ring-asset/3-thumb.py بریده-از-عکس-سه‌چهارم.png assets/rings/ring-NN-thumb.png`

بعد یک ردیف به `assets/rings/rings.json` اضافه شود: `id`، `name`، `face`، `fill`، `thumb`، `"mode": "relight"`،
`spanFactor` (پهنای انگشتر نسبت به انگشت، حدود ۱٫۱۴) و `vStretch` (جبران کوتاه‌دیده‌شدنِ ارتفاع اگر عکس از بالا بوده).
نسبت ارتفاع به پهنای رویه را با عکس انگشتر روی دست واقعی مقایسه کنید («مشبک» حدود ۰٫۳۶ است).

هیچ‌کدام از این‌ها روی عکس دست آزمایش نمی‌شود؛ بعد از ساخت، انگشتر را روی چند عکس دست واقعی ببینید.
