# ابزارهای ساخت انگشتر (آپلود نشود)

این پوشه جزو سایت نیست و روی هاست آپلود نمی‌شود. برای ساختن عکس آماده‌ی یک انگشتر تازه از عکس محصول است.
(پایتون + `opencv-python-headless` + `numpy` لازم است.)

1. `ring-asset/1-cutout.py عکس.png بریده.png پیش‌نمایش.png`: انگشتر را از پس‌زمینه‌ی روشن می‌برد.
   (برای عکس روبه‌رو با پس‌زمینه‌ی تقریباً سفید.)
2. `ring-asset/2-straighten.py بریده.png assets/rings/ring-NN.png پیش‌نمایش.png`: لبه‌های خمیده‌ی عکس را صاف می‌کند،
   پشتِ حلقه را حذف می‌کند و فقط «رویه‌ی انگشتر» را نگه می‌دارد، همان چیزی که از بالای دست دیده می‌شود.
3. `ring-asset/3-thumb.py بریده-از-عکس-سه‌چهارم.png assets/rings/ring-NN-thumb.png`: عکس کوچک برای انتخاب انگشتر.
4. یک ردیف به `assets/rings/rings.json` اضافه شود (اسم، فایل‌ها، `spanFactor`، `vStretch`).

نکته: عدد `vStretch` برای جبران کوتاه‌دیده‌شدنِ ارتفاع رویه در عکس محصول است (دوربین کمی از بالا بوده). با چند عکس دست امتحان و تنظیم شود.
